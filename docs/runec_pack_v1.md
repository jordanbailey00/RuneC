# RuneC Runtime Pack Format v1

Runtime packs are generated by `tools/pack_runtime_data.py` and consumed by
`rc-core/assets.c`.

## Pack Header

Magic: `RCPK0002`

Format version: `PACK_FORMAT_VERSION = 1`

All numeric fields are little-endian.

Header layout:

- `char[8] magic`
- `uint64 index_offset`
- `uint64 index_size`
- `uint64 asset_count`
- `uint8[32] index_sha256`

The index lives at `index_offset` and must hash to `index_sha256`.

## Index

Magic: `RCPI0001`

Index layout:

- `char[8] magic`
- `uint64 entry_count`
- repeated entries:
  - `uint16 path_len`
  - `char[path_len] logical_path`
  - `uint8 compression`
  - `uint64 offset`
  - `uint64 stored_size`
  - `uint64 uncompressed_size`
  - `uint8[32] sha256`

Compression values:

- `0`: stored bytes
- `1`: zlib-compressed bytes

The asset loader rejects packs with the wrong pack magic, index magic, index
hash, unsupported compression method, out-of-range offsets, or mismatched
asset hash after decompression.
